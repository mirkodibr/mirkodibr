## 🚀 Projects

### 📊 [OpenTrace](https://github.com/mirkodibr/OpenTrace) — Self-Hosted Observability Platform *(in active development)*
A self-hosted alternative to Datadog/Honeycomb, built as a full observability stack from scratch. Phase 1 (ingestion, storage, query API, dashboard) is complete: Go microservices publish telemetry through Redpanda (Kafka-compatible) into ClickHouse for high-throughput analytics, with PostgreSQL for metadata, and a React/TypeScript dashboard for live querying. Currently building Phase 2 — a zero-allocation Go SDK for production instrumentation.

`Go` `ClickHouse` `PostgreSQL` `Redpanda/Kafka` `React` `TypeScript` `Docker` `Kubernetes`

---

### 🚗 [Vlera.al](https://github.com/mirkodibr/Vlera.al) — Data-Driven Vehicle Marketplace *(pre-launch)*
A used-car marketplace for Albania that leads with a free valuation engine instead of listings. Python crawlers ingest daily listings from regional marketplaces via scheduled jobs, normalize and deduplicate them, and feed an XGBoost model that produces fair-market vehicle pricing. Next.js frontend, NestJS auction API, Turborepo monorepo.

`Python` `XGBoost` `Next.js` `NestJS` `PostgreSQL` `Prisma` `GitHub Actions`

---

### 🧠 [CerebroSim](https://github.com/mirkodibr/CerebroSim) — Mobile Neural Research Lab
A Flutter app simulating cerebellar learning dynamics based on the **Marr-Albus-Ito theory** of motor learning, with a real-time 3D neural canvas, four simulation environments (Eyeblink Conditioning, VOR, Sine Wave Tracking, Arm Reaching), and a cloud-backed Research Vault via Firebase.

`Flutter` `Dart` `Firebase` `Riverpod` `Domain-Driven Design`

---

### ♠️ [Blackjack AI — PIMC vs Basic Strategy](https://github.com/mirkodibr/AI_CS374) — CS374 Artificial Intelligence
A 6-deck Blackjack simulation comparing a Perfect Information Monte Carlo (PIMC) agent against classic S17 Basic Strategy, benchmarked over 30,000 simulated deals with a Tkinter GUI for interactive play.

`Python` `Monte Carlo Simulation` `Tkinter` `SQLite`
