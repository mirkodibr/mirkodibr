## 🚀 Projects

### 🧠 [CerebroSim](https://github.com/mirkodibr/CerebroSim) — Mobile Neural Research Lab
A high-performance Flutter app simulating cerebellar learning dynamics based on the **Marr-Albus-Ito theory** of motor learning. Features a real-time 3D neural canvas, four distinct simulation environments (Eyeblink Conditioning, VOR, Sine Wave Tracking, Arm Reaching), and a cloud-based Research Vault backed by Firebase where researchers can save and share experimental configurations.

`Flutter` `Dart` `Firebase` `Riverpod` `GoRouter` `Domain-Driven Design`

---

### ♠️ [Blackjack AI — PIMC vs Basic Strategy](https://github.com/mirkodibr/AI_CS374) — CS374 Artificial Intelligence
A full 6-deck Blackjack simulation comparing two AI agents: a **Perfect Information Monte Carlo (PIMC)** agent that infers the remaining deck and runs Monte Carlo rollouts for each action, vs a classic S17 Basic Strategy agent. Benchmarked over 30,000 simulated deals with a Tkinter GUI for interactive play.

`Python` `Monte Carlo Simulation` `AI` `Tkinter` `SQLite`

---

### 🌐 [cerebellum_website](https://github.com/mirkodibr/cerebellum_website) — Web Neural Simulator *(v1 prototype → evolved into CerebroSim)*
The original web prototype that grew into CerebroSim. A Flask web app with client-side cerebellar simulation, user authentication, and persistent experiment storage. Biologically accurate neuron topology (Granule, Golgi, Basket, Purkinje cells) rendered via HTML Canvas and Chart.js.

`Python` `Flask` `SQLAlchemy` `JavaScript` `Chart.js` `Bootstrap`
